## 📖 О чём проект

Гильдии в Albion Online ходят на массовый контент (ZvZ, ганки, сундуки) в группах по
10-50 человек. Выбитый лут продаётся, и деньги делятся между участниками.
Офицер вводит одну команду - и доля у каждого на балансе мгновенно, с уведомлением
в личку, полным аудитом и откатом любой операции.

## ✨ Возможности

### 💰 Экономика

- **`/split 24м`** - распределить лут: до 20 полей с автодополнением ников
(поиск по букве) + текстовое поле для больших сплитов. Понимает `24м`, `24m`, `24000000`
- **`/pay ник`** - выплата игроку (параметр обязателен, ник выбирается из списка)
- **`/payall`** - массовая выплата **с кнопкой подтверждения** (красный ❌ случайный слив исключён)
- **`/payouts`** - очередь на выплату по убыванию сумм
- **`/set`** - ручная коррекция баланса офицером (с записью в лог)

### 📜 Аудит и история

- Каждая операция фиксируется: кто, когда, сколько, кому
- **`/undo [номер]`** - откат **любой** операции
- **`/last`**, **`/history ник`** - журнал, личная история игрока
- Отменённые операции помечаются ↩️ и никогда не стираются

### 📊 Статистика

- **`/week`** - личная недельная сводка: начислено, среднее за сплит,
сравнение с прошлой неделей (без лидербордов, прогресс против себя)

### 🔄 Синхронизация с Google Sheets

- Таблица = живое зеркало базы: балансы, журнал, статус бота, резервная копия
- Новый игрок, добавленный офицером в таблицу, появляется в боте автоматически
- Двусторонняя синхронизация с **защитой от конфликтов** (`last_pushed`-алгоритм)
- Удаление строки из таблицы удаляет игрока из базы (с защитным порогом)

### 📩 Уведомления и мониторинг

- Игрок получает ЛС при начислении и выплате
- **Status-лист**: 🟢 «бот работает», время контакта, число игроков
- **`/check`** - диагностика 7 компонентов: Discord, токен, Google API,
целостность БД, очередь синка, диск, RAM
- **Алерты**: при серии падений бот сам пишет ответственным в ЛС
- **Бэкап**: ежедневный снапшот балансов в скрытый лист таблицы

### 🛡️ Безопасность

- Слэш-команды с проверкой роли **до** разбора аргументов
(обычные игроки не видят офицерских команд и не получают подсказок об их структуре)
- Ошибки показываются только вызвавшему (эфемерные)
- Команды доступны только в выбранных каналах (белый список в интеграциях)
- Секреты только в `.env`, в репозитории их нет

## 🏗 Архитектура

```javascript
 Discord-сервер                    VPS (Moscow)
┌──────────────┐         ┌──────────────────────────────┐
│  /split 24м  │ ◄────►  │  Бот: discord.py + asyncio   │
│  офицер/игрок│ мгнов.  │  ┌────────────────────────┐  │
└──────────────┘         │  │ SQLite - источник      │  │
                         │  │ правды: балансы, логи  │  │
                         │  └────────────────────────┘  │
                         │   синк каждые 30 мин + ЛС    │
                         └───────┬──────────────────────┘
                                 ▼ HTTP POST (ретраи ×3)
                      Google Apps Script (Web App)
                                 │
              ┌──────────────────┼──────────────────┐
              ▼                  ▼                  ▼
      ┌──────────────┐   ┌──────────────┐   ┌──────────────┐
      │ Лист балансов│   │ Лист Logs    │   │ Лист Status  │
      │ (зеркало)    │   │ (аудит)      │   │ + Backup     │
      └──────────────┘   └──────────────┘   └──────────────┘
```

**Почему так:** команды отвечают из локальной SQLite (микросекунды, не зависит от
сети), а Google Sheets работает как витрина для людей - синхронизация идёт фоном.

## 📟 Команды

### Все игроки

| Команда | Описание |
| --- | --- |
| `/balance [ник]` | баланс (свой или чужой, автодополнение) |
| `/history [ник]` | история операций с суммарной статистикой |
| `/week` | статистика за календарную неделю (пн–вс) |
| `/help` | справка (офицеры видят больше) |

### Офицеры

| Команда | Описание |
| --- | --- |
| `/split` | распределить лут (20 полей с поиском ников) |
| `/pay ник` | выплатить игроку (обязательный параметр) |
| `/payall` | выплатить всем (подтверждение кнопкой) |
| `/payouts` | очередь на выплату |
| `/set ник сумма` | ручная правка |
| `/undo [номер]` / `/last` | откат и журнал |
| `/sync` / `/check` | синхронизация / диагностика |

## ⚙️ Установка

```bash
# 1. Зависимости
pip install discord.py aiohttp pytest

# 2. Переменные окружения (.env)
DISCORD_TOKEN=...
GOOGLE_SCRIPT_URL=...
GUILD_NAME=Your Guild
OFFICER_ROLE_IDS=123456789012345678
ALERT_OWNER_IDS=111111111111111111,222222222222222222

# 3. Запуск
python bot.py
# или через systemd (рекомендуется): автоподъём, перезапуск при падении
```

Также нужны: Discord-приложение с ботом, Google-таблица с листами
(балансы / Logs / Status / Backup) и развёрнутый Apps Script Web App.

## 🧪 Тесты

```bash
pytest test_bot.py -v
```

**16 юнит-тестов:** парсинг сумм (`24м`/`24m`/числа), русская плюрализация
(1 игрок / 4 игрока / 11 игроков), нормализация ников (`![🔥] iiO` → `iiO`),
форматирование логов, обращения к БД (временная SQLite через фикстуры).
